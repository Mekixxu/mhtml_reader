## 2. 问题清单（按严重度）

### 🔴 HIGH（1 条）

**H1. 解密失败静默置空 → 下次保存永久清空密码** — HIGH · 数据安全

位置：`core/data/repo/NetworkConfigRepository.kt:58-59`

机制：`withDecryptedPassword()` 用 `runCatching { credentialCipher.decrypt(password) }.getOrElse { "" }` 吞掉所有异常并返回 `""`。结合 `MoreFragment`（编辑框预填解密结果、保存即 `update()` 重加密全字段）：一旦 Keystore key 失效（设备还原/锁屏方变更、数据坏块、非法 base64），UI 显示空密码，用户随手保存即用空密码覆盖 DB 密文，原始密码永久丢失且无任何提示。

```kotlin
// Before
private fun NetworkConfigEntity.withDecryptedPassword(): NetworkConfigEntity =
    copy(password = runCatching { credentialCipher.decrypt(password) }.getOrElse { "" })
```

```kotlin
// After —— 解密失败返回原存值 + 上层标记解密异常，UI 警示并阻断覆盖保存
private fun NetworkConfigEntity.withDecryptedPassword(): NetworkConfigEntity =
    copy(password = runCatching { credentialCipher.decrypt(password) }
        .getOrElse { e -> password.takeIf { it.isNotEmpty() } ?: "" }) // 密文无法解明按原文返回
```

（注：完整的 UI 阻断需在 `MoreFragment` 保存前校验"存在解密异常"标志，见修复 commit。）
